# Персональный Telegram-помощник

Голосовой AI-помощник, который распознаёт русскую/казахскую/английскую речь,
создаёт точные напоминания, раскладывает заметки по проектам, постепенно запоминает
полезный контекст и формирует отчёты.

## Что умеет

- голосовые и аудиофайлы до 20 МБ;
- разовые, ежедневные, еженедельные и ежемесячные напоминания;
- доставка после перезапуска благодаря SQLite;
- автоматические проектные папки и долговременная память;
- обычные и запланированные AI-отчёты по проектам;
- `/memory` для прозрачности и `/forgetme` для полного удаления данных;
- приватный режим: если список разрешённых ID пуст, первый пользователь становится владельцем.

## Mini App

Внутри Telegram доступно полноценное рабочее пространство:

- **Сегодня** — временная шкала ближайших напоминаний и быстрый ввод;
- **Проекты** — заметки, дела и AI-отчёты по каждому проекту;
- **База** — поиск и фильтрация всех заметок и напоминаний;
- **Память** — прозрачный список фактов, которые знает помощник;
- центральный микрофон — запись, быстрый черновик на устройстве и финальная
  расшифровка OpenAI.

Mini App проверяет подпись `Telegram.WebApp.initData` и не доверяет ID,
переданному браузером без подписи. Для локальной визуальной разработки можно
временно задать `DEV_TELEGRAM_USER_ID`; этот режим принимается только с loopback.

## Запуск

Нужен Python 3.9 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
cd webapp && npm install && npm run build && cd ..
python -m assistant_bot.main
```

Секреты хранятся только в `.env.local`, который исключён из Git. Настройки и
описания переменных находятся в `.env.example`.

Чтобы заранее назначить владельцев, укажите числовые Telegram ID в
`ALLOWED_TELEGRAM_USER_IDS`. Несколько ID разделяются запятыми. Если оставить
поле пустым, первый человек, отправивший сообщение боту, станет единственным владельцем.

Для кнопки Mini App задайте публичный HTTPS-адрес в `WEBAPP_URL`. При запуске бот
сам установит кнопку «Открыть WIMAX». Локальный HTTP-сервер слушает `WEBAPP_PORT`
(по умолчанию `8080`).

## Постоянная работа

Процесс должен работать постоянно (например, в Docker, Railway или на VPS).
Если процесс выключен, просроченные напоминания будут отправлены сразу после
следующего запуска. Одновременно запускайте только один экземпляр бота.
